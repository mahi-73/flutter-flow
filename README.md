# FocusFlow 📚

Studying can get messy, and sometimes it's hard to stay focused. So I made **FocusFlow** to make studying a little easier.

It's a simple study website where you can manage your tasks, use a study timer, track your sessions, and listen to relaxing sounds while you work.

## What is FocusFlow?

FocusFlow is a study timer website built with HTML, CSS, and JavaScript. It has a dark theme with purple accents.

## Features ✨

- **Study Timer**
- **To-Do List**
- **Session Log**
- **Relaxing Sounds**
- **Export Sessions**

---

## How to use FocusFlow

Open FocusFlow in your browser. Choose your study time and hit the Start button. Add the tasks you want to work on and mark them as completed when you're done. Check your session log to see your progress. Turn on the background sounds if you feel bored or exhausted while completing your tasks. Export your study log if you want to save it.

Simple, right? Now get that studying done! 😭

---

## Want to run it on your computer? 💻

1. Download this repository from GitHub.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it! You're ready to use FocusFlow. No complicated setup needed.
